    DrugHarness: An Evolvable Agent Harness for Computational Drug Discovery

    DrugHarness: An Evolvable Agent Harness for Computational Drug Discovery

    为什么推给你：Agent 工程（命中：harness）

    Why it is here: Agent engineering (matched: harness)

    DrugHarness 针对药物发现 Agent 的「脚手架不可演进」问题：计算药物发现需要 Agent 组合大量科学操作，并随证据变化调整策略，但现有系统通常把流程写死，无法从执行轨迹中学习。DrugHarness 的做法是把可组合的科学执行与条件化技能归纳耦合起来：环境集成 80 多个科学操作、生物医学资源与任务代码，并保留候选物、结果与产物之间的关联；再从执行轨迹与结果反馈中归纳出带可观测适用条件、推荐动作与支持证据的动作假设，由独立评审 Agent 按来源与证据评估候选技能。它要解决的是「技能怎么长出来、又怎么保证不长歪」。限制是归纳出的技能依赖评审 Agent 的判断，评审本身出错会把错误技能固化，论文也缺少跨真实药物项目的长期验证。

    DrugHarness targets non-evolvable scaffolding in drug-discovery agents: computational discovery requires agents to compose many scientific operations and adapt as evidence changes, yet existing systems hard-code the pipeline and cannot learn from execution traces. DrugHarness couples composable scientific execution with conditional skill induction: its environment integrates 80+ scientific operations, biomedical resources and task-specific code while preserving associations among candidates, results and artefacts; from trajectories and outcome feedback it induces action hypotheses with observable applicability conditions, recommended actions and supporting evidence, and an independent review agent evaluates candidate skills by source and evidence. The problem solved is how skills grow without growing wrong. The limitation is that induced skills depend on the review agent's judgment — an error there fossilises a bad skill — and the paper lacks long-term validation on real drug programmes.

    边界：限制是归纳出的技能依赖评审 Agent 的判断，评审本身出错会把错误技能固化，论文也缺少跨真实药物项目的长期验证。

    Limits: The limitation is that induced skills depend on the review agent's judgment — an error there fossilises a bad skill — and the paper lacks long-term validation on real drug programmes.
