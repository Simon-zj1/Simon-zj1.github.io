Anthropic 的 FlashProve 让模型回答可被密码学验证

Anthropic's FlashProve makes model responses cryptographically verifiable

HN 233 分 · 19MB 证明HN 233 points · 19MB proof

Anthropic 发布开源原型 FlashProve，用 zkSNARK 证明回答确实由某个已承诺权重的模型生成[3]。它解决第三方路由偷换便宜模型、服务端被篡改和审计方无法确认模型身份的问题；机制是离线承诺权重，在线为每个请求生成零知识、简短的推理证明。对 400B 参数 MoE 模型，单张 H100 每秒可生成 100 个以上 token 的证明，约 19MB/1,024-token 请求，24 核 CPU 可在数秒内验证。限制是证明计算仍约为普通推理的 70–95 倍，不隐藏模型架构，也不能证明服务器没有同时在后台训练。

Anthropic released FlashProve, an open-source prototype that uses zkSNARKs to prove a response came from a model with committed weights[3]. It addresses routers quietly substituting cheaper models, tampered servers and auditors who cannot verify model identity; the mechanism commits to weights offline and emits a zero-knowledge, succinct inference proof per request online. For a 400B-parameter mixture-of-experts model, one H100 generates proofs for over 100 tokens per second, at about 19MB per 1,024-token request, with a 24-core CPU verifying in seconds. The limitation is that proving still costs about 70–95 times ordinary inference GPU time, does not hide architecture and cannot show that a server is not training elsewhere.
