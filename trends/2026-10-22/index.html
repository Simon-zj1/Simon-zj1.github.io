    Agentic World Action Models

    Agentic World Action Models

    为什么推给你：机器人与具身智能（命中：机器人、robot、真机）

    Why it is here: Robotics and embodied AI (matched: 机器人, robot, 真机)

    AW-0 针对世界动作模型与 Agent 式机器人各缺一半的问题：前者能预测未来视觉状态，却缺少可复用的组合式技能；后者用代码做规划与推理，却缺少物理动力学的预测依据。作者提出 AW-0，把代码、未来视频与机器人动作作为三条耦合的生成流联合建模在统一的 mixture-of-transformers 架构中：代码专家生成参数化技能例程与控制逻辑，视频与动作专家分别生成未来视觉状态与低层动作指令；代码同时承担结构化的多步预测与控制。它要解决的是「规划」与「物理预测」的整合。限制是三条流的联合训练成本高，代码生成错误会传播到动作层，真机泛化仍需验证。

    AW-0 targets world action models and agentic robotics each missing half: the former predicts future visual states but lacks reusable compositional skills, the latter plans and reasons in code but lacks predictive grounding in physical dynamics. The authors propose AW-0, jointly modelling code, future video and robot actions as three coupled generative streams in a unified mixture-of-transformers architecture: a code expert generates parameterised skill routines and control logic while video and action experts generate future visual states and low-level motor commands, with code structuring multi-step prediction and control. It addresses integrating planning with physical prediction. The limitation is the cost of joint training across three streams, code errors propagating into the action layer, and real-robot generalisation still unverified.

    边界：限制是三条流的联合训练成本高，代码生成错误会传播到动作层，真机泛化仍需验证。

    Limits: The limitation is the cost of joint training across three streams, code errors propagating into the action layer, and real-robot generalisation still unverified.

    HGM-Dual: Lineage-Aware Guided Agent Harness Optimization for Long-Horizon Planning

    为什么推给你：Agent 工程（命中：harness、工具调用、评测）

    Why it is here: Agent engineering (matched: harness, 工具调用, 评测)

    HGM-Dual 针对递归自改进 harness 在规划任务上效率低下的问题：Darwin–Gödel Machine 与 HGM 这类方法在编码任务上有效，因为「改进 Agent 所需的能力」与「被改进的能力」重合；而规划任务要求产出一串满足相互约束的工具调用，这种对齐被打破，开放式自修改会反复探索无效变更、消耗大量评测预算。HGM-Dual 因此提出诊断引导的、带谱系感知的 harness 进化：把 Agent 演化表示为带血统的结构，用诊断信息引导变更方向。它要解决的是自进化系统的预算效率。限制是诊断信号依赖任务设计，跨任务族的迁移性仍需验证。

    HGM-Dual targets inefficient recursive harness self-improvement on planning tasks: methods such as the Darwin-Gödel Machine and HGM work well for coding because the competence needed to improve the agent coincides with the competence being improved, but planning requires emitting a sequence of tool calls satisfying interacting constraints, breaking that alignment, so open-ended self-modification keeps exploring ineffective changes and burns evaluation budget. HGM-Dual proposes diagnostic-guided, lineage-aware harness evolution, representing agent evolution with lineage and using diagnostics to steer changes. It addresses budget efficiency in self-evolving systems. The limitation is that diagnostic signals depend on task design, and transfer across task families remains to be verified.

The paper targets long-term memory for multimodal agents: preserving fine-grained visual evidence while tracking how entities evolve across sessions.
