HTTP2Shell：从 Node 到 Python，HTTP 库的 RCE 波及面持续扩大

HTTP2Shell: an RCE spanning HTTP libraries from Node to Python

HN 177 分 · RCEHN 177 points · RCE

安全研究显示，此前针对 Node 的漏洞已演化出 HTTP2Shell：Python 与其它语言的 HTTP 实现同样受影响，波及大量库与应用[1]。它要解决的是「AI 发现漏洞」之后的新常态——同一类缺陷被快速在多个生态中复现，防守方必须跨语言排查。技术上的根因在 HTTP 解析与帧处理的边界条件，一处实现错误会在多个下游项目中重复出现。参考价值是把「同一漏洞在不同语言生态中的等价实现」纳入补丁清单；限制是受影响版本清单仍在更新，具体利用条件需以厂商公告为准。

Security research shows the Node-targeted flaw has evolved into HTTP2Shell: HTTP implementations in Python and other languages are affected too, spanning many libraries and applications[1]. It addresses the new normal after AI-driven discovery — the same class of bug is quickly replicated across ecosystems, forcing defenders to check multiple languages. The technical root cause is boundary conditions in HTTP parsing and frame handling, where one implementation error recurs across downstream projects. The reference is to include equivalent implementations across language ecosystems in the patch list; the limitation is that affected version lists are still changing, and exploitation conditions defer to vendor advisories.
