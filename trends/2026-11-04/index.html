    Adversarial Speculative Reasoning Improves Long Horizon Agents

    Adversarial Speculative Reasoning Improves Long Horizon Agents

    为什么推给你：Agent 工程（命中：上下文、context）

    Why it is here: Agent engineering (matched: 上下文, context)

    论文针对的是长程 Agent 的推测解码会改变推理结果：标准做法只优化草稿模型接受率，却忽略约 30 步后数值噪声会随机影响准确性。作者训练草稿模型在关键决策点主动“被拒绝”，让目标模型重新验证并高精度生成这些 token，只训练托管的 0.06%–0.28% 参数。机制是在不改变目标模型整体输出分布的前提下，把验证重启变成关键上下文的精度分配器；在复杂编码 Agent 基准上提高了端到端成功率，摘要未报告具体提升点数，对比基线是不同推测解码方案。限制是收益依赖能否稳定识别关键决策点，跨模型和更长轨迹仍需验证。

    The paper targets speculative decoding can alter long-horizon agent reasoning: standard work optimises draft acceptance while overlooking that numerical noise after roughly 30 steps can randomly alter accuracy. The mechanism turns verification restarts into an allocator for context precision without changing the target model's overall output distribution; it improves end-to-end success on complex coding-agent benchmarks, although the abstract gives no point estimate and compares against alternative speculative-decoding schemes. The limitation is dependence on reliably locating critical decisions, with cross-model and longer-horizon validity still to test.

    MDSKILL: Learning to Internalize Skill Memory through Multi-View Distillation for Efficient Dynamic Agent Self-Evolution

    MDSKILL: Learning to Internalize Skill Memory through Multi-View Distillation for Efficient Dynamic Agent Self-Evolution

    为什么推给你：Agent 工程（命中：memory、记忆）

    Why it is here: Agent engineering (matched: memory, 记忆)

    The paper targets noisy, conflicting skill memories that can degrade self-evolving agents after distillation. MDSKILL splits skills into state grounding, action planning and execution control, filters high-quality skills with dynamic metrics, and uses On-Policy Self-Distillation to consolidate complementary branches into one policy. It needs no stronger external teacher and adds no extra inference overhead; against contemporaneous SOTA it improves ALFWorld and WebShop by up to 7.1% and 8.1%. The limitation is that evidence comes mainly from two text-interaction environments and does not yet cover real tool permissions or safety during continual online updates.

    Why it is here: Agent engineering (matched: 上下文, context, benchmark)

    Simon Willison 复现权重空间编程实验时发现，17GB 的 Qwen 3.8 27B 在本机用 46 分 12 秒和 43,506 个推理 token 判断出游戏策略网络的任务，另外三个样例成功、Freeway 失败[2]。它测试的是模型能否只看浮点权重、不执行训练代码就推断网络行为，省去运行环境和大量试验。做法是把网络结构描述与原始权重一起交给长上下文模型推理；效果说明无需前沿闭源模型也能复现，但失败样例和超长耗时表明可靠性仍依赖题意与搜索过程。参考价值是本地可审计的权重理解有了低成本入口；限制是单个模型自述实验，尚不能替代标准化基准。

    While reproducing weight-space programming, Simon Willison found that a 17GB Qwen 3.8 27B on a laptop identified the task of a game-policy network after 46m 12s and 43,506 reasoning tokens, succeeding on three examples and failing Freeway[2]. The method feeds a network description plus raw weights into a long-context model; the result shows a local model can reproduce the idea, while the failure and long runtime expose dependence on task framing and search. The reference is a low-cost, locally auditable entry into weight understanding; the limitation is one self-reported experiment rather than a standard benchmark.

    边界：效果说明无需前沿闭源模型也能复现，但失败样例和超长耗时表明可靠性仍依赖题意与搜索过程。

    Anthropic 展示可证明“回答来自哪个模型”的 FlashProve 原型

    Anthropic demonstrates FlashProve, a prototype proving which model produced an answer

    为什么推给你：Agent 工程（命中：agent、推理）

    Why it is here: Agent engineering (matched: agent, 推理)

    Anthropic 公布开源原型 FlashProve，用密码学证明回答来自指定模型而非路由器替换的模型[5]。它解决的是模型身份与推理来源难以验证的问题，尤其在网关、转售和多模型路由普遍存在时。技术思路是把模型推理与可验证证明绑定，让调用方检查声明与实际执行是否一致；参考价值是为 Agent 审计、合规采购和防替换提供可检验证据。限制是仍是原型，证明开销、模型覆盖范围和生产部署约束尚未完整披露。

    Anthropic published FlashProve, a cryptographic proof that an answer came from the specified model rather than a router substitute[5]. It addresses the difficulty of verifying model identity and inference provenance when gateways, resellers and multi-model routing are common. The approach binds an inference to a verifiable claim so a caller can check that declared and actual execution agree; the reference is testable evidence for agent audits, compliance procurement and anti-substitution. The limitation is that this remains a prototype, with proof overhead, model coverage and production constraints not yet fully disclosed.

    边界：限制是仍是原型，证明开销、模型覆盖范围和生产部署约束尚未完整披露。

    Limits: The limitation is that this remains a prototype, with proof overhead, model coverage and production constraints not yet fully disclosed.
