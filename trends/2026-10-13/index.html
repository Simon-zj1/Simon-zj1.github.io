    Welcome to the Age of Agent Ads: Using On-Policy Attacks to Steer Agentic Decisions

    Welcome to the Age of Agent Ads: Using On-Policy Attacks to Steer Agentic Decisions

    为什么推给你：Agent 工程（命中：评测、检索）

    Why it is here: Agent engineering (matched: 评测, 检索)

    这篇论文提出「Agent 广告」的攻击面：当人们把购物、求职、出行这类排序任务委托给 AI Agent，就出现了通过操纵 Agent 决策牟利的动机[26]。作者指出，现有防御依赖模型的对齐训练与平台条款，因此最有效的已知攻击都是设计成触发「偏离策略（off-policy）」行为的；他们提出在线策略（on-policy）攻击，可以在不把任何单个行为推离已对齐分布的前提下操纵决策。示例攻击分两步：先在产品描述里注入一句对虚构概念的真实否定（「不含 blizyester」）以保持条款合规，这触发 Agent 去搜索网络（「什么是 blizyester？」），进而命中预先布置的、把该虚构概念与有害含义关联起来的网站。对做购物与排序 Agent 的团队，参考价值是对齐训练不是防操纵的充分条件，内容来源与检索链需要独立治理；限制是论文提供的是新攻击面与示例，尚未给出大规模成功率与防御效果的完整评测。

    This paper introduces the attack surface of “agent ads”: as people delegate option-ranking tasks such as shopping, job search and travel to AI agents, incentives appear to steer agentic decisions for profit[26]. Existing defences lean on alignment training and platform terms, so the most effective known attacks are designed to trigger off-policy behaviour; the authors introduce on-policy attacks that steer decisions without pushing any individual behaviour off the aligned distribution. Their example has two steps: inject a truthful negation about a fictitious concept (“does not contain blizyester”) into a product description to stay terms-compliant, which makes the agent search the web (“what is blizyester?”) and surface planted sites associating the concept with harmful implications. For shopping and ranking agents the reference is that alignment training is not sufficient anti-manipulation defence — content provenance and the retrieval chain need separate governance; the limit is that the paper offers a new surface and example without large-scale success or defence evaluations.

    边界：他们提出**在线策略（on-policy）攻击，可以在不把任何单个行为推离已对齐分布的前提下操纵决策**。

    Limits: the limit is that the paper offers a new surface and example without large-scale success or defence evaluations.

    Deleting Code Without Losing Knowledge: Regenerative Software for Python Libraries

    Deleting Code Without Losing Knowledge: Regenerative Software for Python Libraries

    为什么推给你：Agent 工程（命中：评测）

    Why it is here: Agent engineering (matched: 评测)

    这篇报告提出一个大胆的思路：在「软件 3.0」时代，当 Agent 可以在几分钟内重写一个完整程序时，把代码当作唯一真源的传统做法就值得怀疑[29]。它要解决的是代码与知识解耦问题，采用 Fowler 提出的七个原语作为「可再生产软件」的框架：知识存放在被版本跟踪目录中的机器可读记录里，每个单元据此构建一个「再生包」——单个文件，包含模块的架构、意图、决策、公开契约、评测与消费者，但不含实现，外加它可能依赖的那一个模块；开源包 spotregen 实现了这些原语并提供图形界面。作者给出了在安全关键的预测库 spotforecast2-safe 上的首次应用经验。对做代码生成与知识管理的团队，参考价值是把「意图与契约」沉淀为可再生的知识资产，让实现成为可丢弃的产物；限制是这类方法对文档完整性与测试覆盖要求极高，安全关键系统仍需人工把关，报告也只是初步应用。

    This report proposes a radical idea: in the “Software 3.0” era, when an agent can rewrite a complete program in minutes, treating code as the sole source of truth becomes questionable[29]. It addresses decoupling code from knowledge, using Fowler's seven primitives as the framework for regenerative software: knowledge lives in machine-readable records in a tracked directory, and each unit gets a regeneration bundle — a single file holding the module's architecture, intent, decisions, public contract, evaluations and consumers but no implementation, plus the one dependency it may import; the open-source package spotregen implements the primitives with a GUI. The authors report a first application to the safety-critical forecasting library spotforecast2-safe. For code generation and knowledge management teams the reference is to settle intent and contracts as regenerative knowledge assets and let implementations become disposable; the limit is demanding documentation and coverage requirements.

    边界：限制是这类方法对文档完整性与测试覆盖要求极高，安全关键系统仍需人工把关，报告也只是初步应用。

    Limits: the limit is demanding documentation and coverage requirements.

ReForesight 从一个很实际的场景出发：共享通道的机器人需要知道人将会在哪里，而语义占据地图只显示人现在在哪[33]。做法是一个开源 ROS 2 工具包，在基于粒子的语义建图流程上增加实例级的「未来占据预测」与「遮挡后再识别」：一个 36.6k 参数的 MLP 预测每个被跟踪的人或车最多 3 秒后的位置，并有卡尔曼滤波兜底与静止门控；物体自身的点被移动到预测位姿，在图像坐标系里形成「幽灵」点云，无需占据解码器；可选的跟踪器在遮挡后用流程已有的关键点描述子与 3D 度量门控重新关联目标。效果上在四个留出的 CODa 序列上，MLP 把 3 秒终点位移误差均值从 0.728 米（卡尔曼）降到 0.662 米，并在每个序列上都优于同规模 GRU（0.692 米），单实例单 CPU 核耗时 0.04 毫秒。对做移动机器人与服务机器人的团队，参考价值是用极小模型 + 解析兜底替代重型预测网络，往往更适合实时系统；限制是结论限于该数据集与 3 秒预测窗，拥挤场景与多类交通参与者下的表现需要进一步验证。

ReForesight starts from a practical setting: robots sharing walkways need to know where people will be, while semantic occupancy maps show only where they are[33]. The result is an open-source ROS 2 toolkit adding instance-level future occupancy and re-identification after occlusion to a particle-based semantic mapping pipeline: a 36.6k-parameter MLP predicts each tracked person or vehicle up to 3 seconds ahead, guarded by a Kalman fallback and a stationary gate, and the object's own points are moved to the forecast pose to form a “ghost” point cloud in the map frame without an occupancy decoder; an optional tracker re-associates objects after occlusion using keypoint descriptors the pipeline already computes plus a metric 3D gate.
