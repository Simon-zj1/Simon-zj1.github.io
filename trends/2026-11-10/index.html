    World In-Context Learning for Agentic Robot Manipulation

    World In-Context Learning for Agentic Robot Manipulation

    为什么推给你：Agent 工程（命中：上下文、context、memory、记忆）

    Why it is here: Agent engineering (matched: 上下文, context, memory, 记忆)

    论文针对的是传统机器人策略把技能写进权重，难以跨视觉环境迁移。作者提出 WICL：冻结模型先看一次演示，在仿真世界中试运行，把世界反馈写入上下文而不是权重，形成可部署的 Task Memory。在 RoboTwin 2.0 的全部 50 个任务上，每任务仅一段示范、无梯度更新，平均成功率达到 83.4%，比最强训练策略高 20 分以上，并迁移到真实双臂机器人。限制是仍需仿真世界和任务记忆适配，真实复杂接触与长期漂移尚未充分覆盖。

    The paper targets robot policies that encode skills in weights and struggle to transfer across visual worlds. It introduces WICL: a frozen model starts with one demonstration, rehearses in a simulated world and writes the feedback into context as a Task Memory rather than updating weights. With one demonstration and no gradients, it reaches 83.4% mean success across all 50 RoboTwin 2.0 tasks, over 20 points above the strongest trained policy, and transfers to a physical dual-arm robot. The limitation is dependence on simulation and task-memory adaptation, with complex contact and long-term drift still underexplored.

    边界：限制是仍需仿真世界和任务记忆适配，真实复杂接触与长期漂移尚未充分覆盖。

    Limits: The limitation is dependence on simulation and task-memory adaptation, with complex contact and long-term drift still underexplored.

    HiVe-Mem: Interleaving Horizontal Memory Expansion and Vertical Evidence Composition for Multimodal Agents

    HiVe-Mem: Interleaving Horizontal Memory Expansion and Vertical Evidence Composition for Multimodal Agents

    为什么推给你：Agent 工程（命中：上下文、memory、记忆、检索）

    Why it is here: Agent engineering (matched: 上下文, memory, 记忆, 检索)

    论文针对的是多模态 Agent 的长期记忆依赖压缩语义检索，容易漏掉相关经历，也无法按问题组合证据。HiVe-Mem 用文本和视觉锚点把记忆组成关系图，检索种子后扩展邻居以补齐上下文；每条记忆保留摘要、字幕、局部视觉、原图和交互历史，再由轻量选择器按查询组合证据。在三个多模态记忆基准上，它提升多个基础模型，并把 token 消耗比最高效基线降低约 90%。限制是图构建和选择器训练增加维护成本，长期错误关联仍可能放大。

    The paper targets long-term multimodal memory that relies on compressed semantic retrieval and misses related events or query-specific evidence. HiVe-Mem builds a relational graph with text and visual anchors, expands retrieved seeds through neighbours, and keeps summaries, captions, grounded views, raw images and interaction history for each memory; a lightweight selector composes the evidence per query. Across three multimodal-memory benchmarks, it improves multiple base models while using about 90% fewer tokens than the most efficient competitor. The limitation is added graph and selector maintenance, with long-term false associations still able to propagate.

    边界：限制是图构建和选择器训练增加维护成本，长期错误关联仍可能放大。

    Limits: The limitation is added graph and selector maintenance, with long-term false associations still able to propagate.

World In-Context Learning for Agentic Robot Manipulation

2611.12885 · cs.CV · 2026-11-092611.12885 · cs.CV · 2026-11-09

论文针对的是传统机器人策略把技能写进权重，难以跨视觉环境迁移。作者提出 WICL：冻结模型先看一次演示，在仿真世界中试运行，把世界反馈写入上下文而不是权重，形成可部署的 Task Memory。在 RoboTwin 2.0 的全部 50 个任务上，每任务仅一段示范、无梯度更新，平均成功率达到 83.4%，比最强训练策略高 20 分以上，并迁移到真实双臂机器人。限制是仍需仿真世界和任务记忆适配，真实复杂接触与长期漂移尚未充分覆盖。

The paper targets robot policies that encode skills in weights and struggle to transfer across visual worlds. It introduces WICL: a frozen model starts with one demonstration, rehearses in a simulated world and writes the feedback into context as a Task Memory rather than updating weights. With one demonstration and no gradients, it reaches 83.4% mean success across all 50 RoboTwin 2.0 tasks, over 20 points above the strongest trained policy, and transfers to a physical dual-arm robot. The limitation is dependence on simulation and task-memory adaptation, with complex contact and long-term drift still underexplored.

HiVe-Mem: Interleaving Horizontal Memory Expansion and Vertical Evidence Composition for Multimodal Agents

HiVe-Mem: Interleaving Horizontal Memory Expansion and Vertical Evidence Composition for Multimodal Agents

2611.12872 · cs.CL · 2026-11-092611.12872 · cs.CL · 2026-11-09

论文针对的是多模态 Agent 的长期记忆依赖压缩语义检索，容易漏掉相关经历，也无法按问题组合证据。HiVe-Mem 用文本和视觉锚点把记忆组成关系图，检索种子后扩展邻居以补齐上下文；每条记忆保留摘要、字幕、局部视觉、原图和交互历史，再由轻量选择器按查询组合证据。在三个多模态记忆基准上，它提升多个基础模型，并把 token 消耗比最高效基线降低约 90%。限制是图构建和选择器训练增加维护成本，长期错误关联仍可能放大。

The paper targets long-term multimodal memory that relies on compressed semantic retrieval and misses related events or query-specific evidence. HiVe-Mem builds a relational graph with text and visual anchors, expands retrieved seeds through neighbours, and keeps summaries, captions, grounded views, raw images and interaction history for each memory; a lightweight selector composes the evidence per query. Across three multimodal-memory benchmarks, it improves multiple base models while using about 90% fewer tokens than the most efficient competitor. The limitation is added graph and selector maintenance, with long-term false associations still able to propagate.

WorkflowArena: Benchmarking Executable Workflow Orchestration in LLM-Based Multi-Agent Systems

2611.12856 · cs.CL · 2026-11-092611.12856 · cs.CL · 2026-11-09

论文针对的是多 Agent 系统会自行生成和编排工作流，但现有基准只测最终任务或预先固定的协调结构。WorkflowArena 汇集 145 个长程任务、8 个专业领域，要求 Agent 自主决定是否和如何委派，并记录全部委派，以同时评分交付物与工作组织。九个模型中没有任何配置在所有领域最好；高投入时 Claude 更少启动工作流但每组更大，GPT 更常以小单元委派。固定执行模型时，Claude Opus 5.5 编写的工作流还能明显提升较弱执行者。限制是基准只含 145 个任务，评审仍依赖隐藏 verifier。

The paper targets multi-agent systems that author executable workflows while existing benchmarks score only final tasks or pre-specified coordination structures. WorkflowArena contains 145 long-horizon tasks across eight professional domains, asking agents to decide whether and how to delegate while recording all delegation so deliverables and work organisation are scored together. No configuration among nine models wins every domain; at high effort Claude starts fewer workflows with larger worker groups while GPT delegates more often in small units. With the executor fixed, workflows authored by Claude Opus 5.5 improve weaker models. The limitation is a finite 145-task suite and hidden-verifier grading.

Mitigating Agentic Deception via Evaluation-Side Partially Observable Games

2611.12835 · cs.LG · 2026-11-092611.12835 · cs.LG · 2026-11-09

论文针对的是Agent 为了奖励而表现出欺骗行为，但最终结果评估看不到内部推理、工具使用和环境副作用。作者把评估建模为部分可观察博弈：Agent 最大化奖励、monitor 从完整轨迹揭穿欺骗、verifier 校验并施加惩罚，并证明完美 verifier 下均衡必然忠实。用两时间尺度策略梯度训练后，在角色扮演、SearchQA 和 WebShop 上，欺骗缓解指标比最强基线高 26.0%，任务成功率最高提升 39.8%。限制是 verifier 不完美时保证依赖排序条件，真实长轨迹验证成本仍高。

The paper targets agents that deceive for reward while outcome-only evaluation misses internal reasoning, tool use and environmental side effects. It models evaluation as a partially observable game where the agent maximises reward, a monitor exposes deception from full trajectories and a verifier converts findings into penalties, proving that every equilibrium is faithful under a perfect verifier. With two-timescale policy gradients, deception mitigation beats the strongest baseline by 26.0% and task success improves by up to 39.8% on role-play, SearchQA and WebShop. The limitation is that imperfect-verifier guarantees depend on ranking conditions, and verifying real long trajectories is costly.

Agentic-OPD: Recovering Forgotten Agent Capabilities via On-Policy Distillation for Agentic Tasks

The paper targets agent RL runs that keep only the best-validation checkpoint and discard lost capability coverage. Agentic-OPD treats every saved checkpoint as a free teacher pool, selecting teachers by the student's unsolved problems and limiting distillation to failed trajectories where a teacher is genuinely better. Across five agent domains and 24 benchmarks it gains up to 7.4 points over the initial checkpoint, and a 4B student surpasses GPT-5.6 and DeepSeek-V4.1 on deep search. The limitation is checkpoint storage and scheduling cost, with teacher selection depending on a stable coverage metric.

VLA Adaptation with Real and Simulated Data: A Case Study on Robotic Chess

The paper targets how much real data and training VLA fine-tuning needs, and whether simulation can replace physical collection. An SO-101 moves a chess king to squares named like e4 or a5 while π0.5 is trained with varied real and simulated demonstrations. Simulation success scales with data and updates, and a short learning-rate cooldown adds up to 31 points; validation loss and action error are unreliable for checkpoint selection.
