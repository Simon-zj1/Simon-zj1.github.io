    为什么推给你：Agent 工程（命中：评测、检索）

    Why it is here: Agent engineering (matched: 评测, 检索)

    Tracely 把生产环境的 Agent 轨迹变成 CI/CD 里的回归测试：给轨迹打分、聚类失败、冻结成可重放的测试用例，并在 PR 让指标退化时直接拦住，支持自托管[24]。它要解决的是Agent 质量无法像代码一样被回归验证：传统 CI 靠单元测试，而 Agent 的输出是概率性的，必须靠「真实轨迹 + 判定器」才能发现退化。实现上把 trace 当作一等数据源，用 ClickHouse 存储与检索，再把聚类出的失败样本固化成可重复运行的用例，这套流程恰好补上「可重放」这一环。值得借鉴的是把线上轨迹直接回流成测试资产，而不是等用户投诉再手工复现；限制是项目 2026-10-11 才创建，判定器的准确性与大规模轨迹的存储成本仍需实测评测。

    Tracely turns production agent traces into regression tests inside CI/CD: grading traces, clustering failures, freezing them into replayable test cases and blocking PRs that regress, self-hostable[24]. It addresses the inability to regression-test agent quality the way code is tested: CI relies on unit tests, but agent outputs are probabilistic, so only real traces plus graders reveal degradation. The implementation treats traces as first-class data, stores and queries them in ClickHouse, then freezes clustered failures into repeatable cases — filling in the replayability link. Worth borrowing is feeding production traces back into test assets instead of reproducing by hand after a complaint; the limitation is that the project dates from 2026-10-11, and grader accuracy plus storage cost at scale still need measurement.
