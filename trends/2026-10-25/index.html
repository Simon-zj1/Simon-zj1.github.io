The technical crux is freezing a browsable world into a controlled corpus and reproducing it offline. TARSphere is a robot-oriented full-stack framework for long-horizon embodied agents[28]. It addresses fragmentation across embodied-agent modules: perception, planning, execution and evaluation are implemented separately and hard to debug end to end. Worth borrowing is building an embodied agent as a composable full stack; the limitation is that the project is new and cross-hardware adaptation needs validation.
