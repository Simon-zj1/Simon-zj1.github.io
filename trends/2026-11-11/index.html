    ReTrace: Distilling Tool-Using Agents into Planner-Free Workflows

    ReTrace: Distilling Tool-Using Agents into Planner-Free Workflows

    为什么推给你：Agent 工程（命中：编排）

    Why it is here: Agent engineering (matched: 编排)

    论文针对的是业务流程每次运行都调用 LLM 规划每一步，导致延迟和成本过高。ReTrace 从 SOP 和少量已记录轨迹中抽取每一步的条件，把 Agent 推理编译成由代码执行、可跨编排平台迁移的工作流。在生产平台 79 个流程上，工作流达到 93.8% 完成率，Agent 为 96.8%，但每任务成本低 24%；τ²-Bench 成功率为 75.8% 对 80.6%，延迟从 170 秒降到 1.3 秒。限制是规则抽取依赖高质量轨迹，流程变化后需要重新修复。

    The paper targets business-process automation calling an LLM to choose every step on every run, creating excessive latency and cost. ReTrace extracts each step's condition from an SOP and a few logged trajectories, compiling the agent's reasoning into a code-executed, portable workflow. On 79 production procedures it reaches 93.8% completion versus 96.8% for the agent at 24% lower cost; on τ²-Bench it scores 75.8% versus 80.6% while latency falls from 170s to 1.3s. The limitation is dependence on high-quality traces, with changes to procedures requiring renewed repair.

    边界：限制是规则抽取依赖高质量轨迹，流程变化后需要重新修复。

    Limits: The limitation is dependence on high-quality traces, with changes to procedures requiring renewed repair.

    Comparative Analysis of Agent Evaluation Frameworks: Stability, Detection, and Discovery in Enterprise Analytics Agents

    为什么推给你：Agent 工程（命中：评测）

    Why it is here: Agent engineering (matched: 评测)

    论文针对的是企业分析 Agent 的评测框架缺少稳定性、已知风险检测和未知故障发现的可比数据。作者用冻结执行轨迹比较 trace-based LLM judging、仅文本评审和确定性启发式三类框架：97% 配置达到稳定性阈值，trace-based 在 72 个已知风险案例上取得 F1=0.90，而文本评审误报多 5 倍；未知风险发现中两种方法找到 24 个互不重叠的失败。限制是研究只在两个受控 Agent 和固定场景中进行，尚未覆盖全部企业工具与权限组合。

    The paper targets a lack of comparable stability, known-risk detection and unknown-failure discovery data. Using frozen traces, it compares trace-based LLM judging, text-only judging with red-teaming and deterministic heuristics: 97% of configurations clear the stability threshold, trace-based judging reaches F1=0.90 on 72 known risks while text-only produces five times more false alarms, and unknown-risk discovery finds 24 failures with no overlap between functional and security testing. The limitation is a controlled study of two agents and selected tools, not every enterprise permission combination.

The paper targets memory-augmented VLAs that uniformly sample frames by time and may mistake elapsed time for task progress. The limitation is added storage and retrieval cost, and incorrect link granularity can still carry bad evidence into new tasks.
