它是什么

What it is

一个「自己考自己」的工具：材料由你提供，卷子自动生成，判分逐条摊开。它不替你学习，只回答一个问题——你到底哪一点没学会。

A tool for testing yourself on your own material. It writes the exam, then shows the grading point by point. It does not study for you — it answers one question: what exactly have you not learned.

逐得分点判分

Point-by-point grading

简答题不给一个 0–100 的黑盒分数，而是逐条判断「这个要点说到了没有」，再按权重合成总分。

A written answer is judged claim by claim — was this rubric point covered — then combined by weight, instead of one opaque 0–100 score.

不确定就标出来

Uncertainty is surfaced

判定强度不足的题目标记「待复核」，给出分数区间，并且不计入掌握度。宁可承认没把握，也不假装确定。

A weakly judged point turns the question into "needs review" with a score range, excluded from mastery. Better to admit doubt than to fake certainty.

一个知识点，一页图解

One page per concept

概念给类比、流程给步骤、算法用一个例子走一遍。产出一页单文件 HTML，可离线打开、可发给别人。

Analogies for abstract ideas, steps for processes, a worked example for algorithms — delivered as a single HTML page you can open offline.

怎么判分

How grading works

三个环节分工固定，不能混：出题交给生成式模型，客观题交给代码，主观题逐点判定。

Three stages with fixed roles: a generative model writes the exam, code grades the objective questions, and written answers are judged point by point.

01出题与拆点Generate模型切分知识点、出题、拆评分点Model splits topics, writes questions and rubric points
02客观题判分Deterministic代码归一化比对，免费且可复现Normalised comparison in code — free and reproducible
03主观题判分Point by point每个得分点一条判定，代码加权合成One judgment per rubric point, combined in code
  • 判定层不写解释、不生成文字，只回答很窄的问题并给出概率；同一套接口可以换成不同的判定引擎。
  • The grading layer writes no prose: it answers a narrow question and returns a probability. The same interface can be backed by different engines.
  • 简答题按得分点拆成多个原子问题，每个问题自带它要判的那一点与原句证据；最后减去「与材料矛盾」「编造材料外事实」两项扣分。
  • A written answer is split into atomic questions, each carrying its own rubric point and evidence span, then penalised explicitly for contradicting the material or inventing facts.
  • 讲解类产物走同一条契约：模型只产出内容 JSON，HTML 由渲染器生成——版式、字号、手机端换行因此是代码保证的，而不是运气。
  • Explainers follow the same contract: the model returns content JSON, the renderer produces the HTML — layout, type size and mobile wrapping are code guarantees, not luck.

交卷之后

After the exam

大多数工具在给出分数时结束，而学习从这里才开始。低分题进错题本，并按 FSRS 排期：今天、明天、下周，直到你真的记住。

Most tools stop at the score. Learning starts there: weak questions enter the mistake log and get scheduled with FSRS — today, tomorrow, next week, until you actually remember them.

错题本与掌握度

Mistake log and mastery

错题按知识点聚合，一键重考；重考答对后自动移出。待复核的题目不参与掌握度计算。

Mistakes are grouped by topic and can be retaken; a correct retake removes them. Flagged questions never affect mastery.

复习按遗忘曲线排期

Review on a forgetting curve

复习卡片带题型、上次得分、已复习次数与遗忘次数，到期才出现在队列里。

Due cards show question type, last score, review count and lapse count — and only appear when they are due.

两种模型来源，你选

Two ways to pay for models

不用为了试用去申请 API Key，也不用把 Key 交给不放心的地方——两条路随时可切换。

You do not need an API key to try it, and you never hand a key to a place you do not trust. Switch any time in settings.

用平台额度

Platform credits

注册送 300 积分（约 30 万 token 等值），按 token 消耗扣积分：1 积分 = 1000 token 等值，按官方价 1.5 倍计费。余额与每一笔扣费都能在设置页逐笔核对。

300 credits on signup (about 300k tokens of value), spent by token usage: 1 credit = 1,000 tokens, billed at 1.5× the official price. Every debit is itemised in settings.

用你自己的 Key

Bring your own key

支持 DeepSeek、智谱 GLM、通义千问、Kimi、OpenAI、Claude 等；Key 加密存储，只在你的请求里使用，不消耗平台积分。

DeepSeek, GLM, Qwen, Kimi, OpenAI, Claude and more. The key is encrypted, used only for your own requests, and spends no credits.

选了哪条路就是哪条路：选平台额度不会偷用你存的 Key，选自己的 Key 也不会悄悄扣你的积分。

Whichever you pick is what runs: platform credits never touch your stored key, and your own key never silently spends credits.

可核对，也带得走

Verifiable, and portable

「凭什么相信这个分数」不该靠信任。四件事被写成了代码里的契约，而不是宣传语。

"Why should I trust this score" should not require trust. Four things are enforced as contracts in code:

材料事实必须可定位

Material facts are locatable

题目出处与每个得分点的依据必须逐字出现在材料里，字段都带标签：材料原文 / 模型补充。图解里的引文同样要过这一关，定位不到就降级标记。

Sources and rubric evidence must appear verbatim in the material, and every field is tagged material or model-added. Explainer citations pass the same check.

覆盖率不假装完整

Coverage is not faked

材料会被切成要点单位，没被出题覆盖的部分如实列出（例如「覆盖 11/14」）。

The material is split into units and anything no question covers is listed (for example "11/14 covered").

判错有出口

Wrong grades have an exit

每题下面有「这题判错了？」，上报会冻结当时的判定现场并进入复核。

Every question has a "graded wrong?" form; a report freezes the judgment as it was and goes to review.

数据是你的

Your data, your call

可导出 Markdown、Anki CSV 与完整备份 JSON；删材料会连带删掉派生试卷与判定，账号可一键删除。

Export Markdown, Anki CSV or a full JSON backup; deleting a material removes its exams and judgments, and the account can be deleted outright.
